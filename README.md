# git-langflow
AI Learning Companion &amp; Academic Support (Langflow)

# Installation and Setup Instructions
1. Navigate to https://github.com/langflow-ai/langflow and download Langflow Desktop.
2. Execute the installer file.
3. Import the project JSON file into the application.
4. Download the context folder containing the necessary data files.
5. Copy the file path of `apu_campus_info` and paste it into the campus information reader component.
6. Copy the file path of `sample_lecture_notes` and paste it into the corresponding data reader component.
7. Remove any quotation marks (`" "`) from the entered file paths.
8. Configure and connect your Google AI API key.
9. Open the playground and initiate execution.
